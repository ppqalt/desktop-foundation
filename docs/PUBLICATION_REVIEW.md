# Publication review (2026-10-01)

The preparation scan inspected 708 reachable history objects and tracked text
for private-key headers, credential assignments, common GitHub/OpenAI token
formats and Bluetooth link keys. No matching secrets were found. This is a
pattern audit, not a guarantee against every possible secret format. No contents
of potential credentials were printed. Browser/Spotify account directories,
Bluetooth pairing database, caches and `work/` are outside tracked files.

The remaining literal MAC addresses in tests are synthetic fixtures. A live-user
absolute path in reliability instructions was replaced with a checkout-relative
command. Tops monitor/output settings remain intentionally isolated in profiles;
portable default does not import them. Generated paths use HOME/XDG directories.

Fonts include upstream OFL and trademark notices and all source hashes match.
Native Nothing code includes AGPL-3.0 license and upstream attribution/source pins.
No upstream web UI artwork or proprietary application binaries are vendored.
Spotify/Spicetify archives are fetched during personal installation, not committed.
Marketplace uses the upstream manual-release installation path:
https://github.com/spicetify/marketplace/wiki/Installation

PUBLICATION BLOCKERS:
- `wallpapers/wallhaven-135w7w.png` was user-selected from the existing personal
  wallpaper. Its filename/source identification does not establish redistribution
  rights. Confirm permission or substitute a distributable image before public
  GitHub publication (including old Git history that contains this image).
- There is no repository-wide license declaration for the project's original
  shell/configuration code. Choose one before claiming the whole project is
  licensed for public redistribution. The native AGPL obligations remain separate.

Nothing was published, and no remote is configured. Private fresh-install testing
can use a verified off-machine Git bundle; image publication rights and personal
backup are separate concerns.
