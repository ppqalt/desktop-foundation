# Application launcher

Super+Space opens the launcher. Type a name or keyword, select with arrows, Tab
or the wheel, then press Enter. Escape closes it. Shift+Tab moves backward and
PageUp/PageDown moves by the visible page.

Search ranks names, descriptions and desktop-entry keywords. Quickshell watches
installed desktop entries; their command arguments and working directory are
used when launching. Terminal applications open in Kitty.

Launcher, clipboard, Bluetooth and session menus use the shared graphite card,
rows, key hints and entrance/exit timing. Held menu shortcuts fire once per press.
