# Official Google Material reference index

This catalogue lists **252 canonical foundation, style and component pages**
from [Google's published sitemap](https://m3.material.io/sitemap.xml), retrieved
2026-10-30. It links to Google's rules; it does not reproduce or replace them.
The [site home](https://m3.material.io/), [foundations](https://m3.material.io/foundations)
and [component catalogue](https://m3.material.io/components) remain the entry
points when Google adds or reorganizes guidance.

## How agents must use these references

- Read the relevant overview, specifications, guidelines and accessibility pages
  before modifying that component. Consult foundations/styles as well as its shape.
- Google's live documentation is authoritative. This dated link index is a
  discovery aid, not proof that every page has been read or frozen locally.
- Some pages require JavaScript. A successful HTTP response does not mean their
  content was inspected. Use a rendered browser or Google's implementation when
  necessary, and state what could not be verified.
- Record the source for copied measurements. Distinguish specification values
  from our desktop adaptations and current approximations.
- Keep [the UI standard](FOUNDATION_UI_STANDARD.md) as the Foundation engineering
  contract: no shadows, shared semantic palette, universal keyboard access and
  the explicitly documented desktop motion/geometry choices.
- Do not vendor complete Google documentation or third-party summaries into the
  repository. Small original engineering notes and direct official links keep
  guidance maintainable and avoid stale, unlicensed copies.

## Official implementation references

- [Google's Material 3 Compose guide](https://developer.android.com/develop/ui/compose/designsystems/material3)
- [AndroidX Material 3 source](https://android.googlesource.com/platform/frameworks/support/+/androidx-main/compose/material3/material3/)
- [Material Components Android](https://github.com/material-components/material-components-android)
- [Material Web](https://github.com/material-components/material-web)
- [Material Color Utilities](https://github.com/material-foundation/material-color-utilities)

These are reference implementations, not dependencies to add to our QML shell.
Check the implementation/version before assuming a library contains the latest
Expressive behavior; a Material-branded library is not itself the full standard.
