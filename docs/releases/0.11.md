# Desktop foundation 0.11

Niri-first desktop update, including all completed work since 0.10.

## Changes

- Bluetooth popup now includes a native radio on/off switch and recovers from
  software rfkill blocks when turning Bluetooth on.
- Allowlisted Brave Origin Nightly preferences, search, extensions and Wayland
  flags can be reproduced without exporting accounts, cookies or credentials.
- Normal windows use equal active/inactive 96% opacity; Kitty retains native
  90% background transparency and opaque text. Blur remains enabled.
- Kitty Ctrl+A creates a real selection across retained screen and scrollback;
  Ctrl+C copies it. Ctrl+A itself does not copy. The 10,000-line limit is unchanged.
- Parallel session startup avoids login-time unit reloads and unnecessary waits;
  popup delivery waits for the shell IPC interface. Startup reporting and live
  profiling are available for diagnosis.
- Optional reversible non-Plymouth boot setup derives AppArmor LSM arguments
  from the installed kernel, preserves main/LTS fallback images and supports
  safe recovery of interrupted boot transactions.
- Greeter owns/reset-clears tty1 while boot console output uses tty8, preventing
  late system status lines from corrupting tuigreet. Reboot validation succeeded.
- Firmware installation includes mkinitcpio-firmware with repository/AUR fallback.
- Optional boot optimization keeps a visible one-second GRUB menu, moves mirror
  scheduling off network-online and opts out of direct Wine executable dispatch.
  Explicit Wine invocation remains available. Rollback backups are retained.
- CachyOS update tray autostart is suppressed; cachy-update remains available.

## Measurements and limitations

On Tops, two post-change boots reported 26.747s and 26.745s, compared with a
34.809s baseline median. Most of that difference is network waiting leaving the
reported boot completion path; greetd started about 0.65s earlier. These are
machine-specific observations, not promised installation results. See
[boot measurements and rollback](../boot-optimization.md).

This remains a prerelease installation candidate. A full fresh-machine acceptance
pass is still required. The tested Niri build supports native blur/background
effects and tuigreet supports the Matrix background. Stock packages may differ.
Kitty selection uses a small in-process kitten with native selection endpoints;
user acceptance of the final interaction remains pending. No CS2 optimization
changes are included: that investigation was stopped before configuration edits.

Release checks passed: repository static/config checks, nine Rust tests,
53 Python tests, search tests and live Niri IPC regression checks. A tracked-text
credential-pattern scan found no matches; this does not certify every secret format.

## Install

On a fresh supported Arch/CachyOS system, as your normal sudo-enabled user:

```sh
sudo pacman -Syu --needed git
git clone --branch v0.11 https://github.com/ppqalt/desktop-foundation.git
cd desktop-foundation
./scripts/install --dry-run
./scripts/install
```

The default profile is portable; do not select Tops on lucky38. Use `--core` for
Firefox/Nautilus instead of personal application additions. Add `--clean-boot`
only when choosing the documented GRUB/mkinitcpio changes. Reboot manually,
log into Niri, and run `./scripts/session-acceptance` and `./scripts/doctor --personal`
(or doctor without --personal for a core installation).

Existing installations should retain their checkout/backups, fetch and inspect
v0.11, then follow [installation](../installation.md) and the individual boot
transaction instructions rather than deleting the checkout or blindly creating
another boot transaction. Credentials, Bluetooth pairings and app histories
remain local. Source archives are generated automatically by GitHub.
