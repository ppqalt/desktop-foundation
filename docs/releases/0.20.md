# Desktop Foundation v0.20

A Niri desktop with wallpaper-derived graphite colors, shared menus and Rust
backends for system operations.

## Included

- Rust clipboard storage, screenshots, audio feedback, Bluetooth operations,
  palette generation, package counts and session startup.
- Consistent launcher, clipboard, Bluetooth, earbud and session menus with full
  keyboard navigation, scrolling and shared animations.
- First-frame session-menu entrance and animated closure; single-press menu shortcuts.
- Volume with immediate bar updates, 100 ms visibility fades and 3% steps.
- Native single-column centering, manual centering and a toggleable corner clock.
- Nothing/CMF battery reporting, noise control, equalizer, gestures and device
  settings; SBC and SBC XQ playback profiles where offered by PipeWire.
- Wallpaper-driven shell, terminal, notification, GTK, Brave and Spotify colors.
- Core and full installers, application defaults, Matrix greeter and AppArmor /
  GRUB helpers.
- Kitty/Fish/Fastfetch setup and bundled Google Sans fonts.

## Install

```sh
git clone --branch v0.20 https://github.com/ppqalt/desktop-foundation.git
cd desktop-foundation
./scripts/install-core
# Include Spotify, ChatGPT and Steam:
./scripts/install-all
```

Use `--dry-run` to inspect the installation and `--no-greeter` to keep an existing
login manager. [Installation](../installation.md) lists the remaining options.
